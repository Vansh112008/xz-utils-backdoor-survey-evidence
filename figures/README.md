# Figures

This folder contains the source files for figures prepared for the XZ Utils Backdoor survey paper. The diagrams are written in Mermaid Markdown and should be rendered to image files (SVG or PNG) and checked in the final document if the assignment template requires embedded figures.

1. **Figure 1 – Literature selection process:** conceptual workflow for identification, screening, eligibility and inclusion. Numerical counts are intentionally omitted until actual screening records are available.
2. **Figure 2 – Taxonomy of software supply-chain attacks:** categories and representative attack techniques.
3. **Figure 3 – Software supply-chain security lifecycle:** security checkpoints from development through deployment and monitoring.

The source files are:
- `literature-selection-flowchart.md`
- `attack-taxonomy.md`
- `security-lifecycle.md`

Do not describe Figure 3 as a trends chart; it is a lifecycle diagram.
