## Project Overview

This repository contains the research evidence and supporting materials for an individual literature survey on the XZ Utils Backdoor discovered in March 2024.

The survey examines how malicious code was introduced into XZ Utils, how the compromised library could interfere with OpenSSH authentication, and what the incident reveals about open-source software and software supply-chain security.

## Research Objectives

1. Examine the background and timeline of the XZ Utils backdoor incident.
2. Understand the technical mechanism behind CVE-2024-3094.
3. Analyse the role of software supply-chain vulnerabilities and maintainer trust.
4. Review detection, response and mitigation approaches.
5. Identify security lessons for open-source projects and software development ecosystems.
